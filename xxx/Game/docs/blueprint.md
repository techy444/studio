# **App Name**: CodeDuel Arena

## Core Features:

- Problem Explorer: Browse coding problems by topic, difficulty, and keywords fetched from Firestore.
- In-Browser IDE: Write, run, and submit code with syntax highlighting and error detection.
- Real-Time Battles: Challenge another online player with a shared coding problem. Winner decided based on time to completion.
- Dynamic Leaderboard: Keep track of user ranks, points, and win/loss ratios in real time, stored in Firestore.
- Code Snippet Explainer: Provide code snippets, then receive line-by-line explanations from an AI tool that acts like a senior engineer. The tool understands when a specific line relates to general programming paradigms such as dependency injection.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) for a coding-focused and intense atmosphere.
- Background color: Dark gray (#282828) to reduce eye strain during long coding sessions.
- Accent color: Electric purple (#BF00FF) to highlight interactive elements.
- Headline font: 'Space Grotesk' sans-serif for a modern, tech-oriented title. Body font: 'Inter' sans-serif.
- Code font: 'Source Code Pro' monospace font for displaying code snippets.
- Use minimalistic icons related to coding concepts, challenges, and competition.
- Smooth animations for page transitions and loading screens to maintain user engagement.
